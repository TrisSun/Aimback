```
                   ┌────▼──┐ ┌─▼────────┐ │
                   │SQLite │ │  Redis   │◄┘
```

## 3. 首次部署流程

### 3.1 系统依赖

```bash
sudo apt-get update
sudo apt-get install -y python3.10-venv nginx redis-server
```

### 3.2 拉代码 + 建虚拟环境

```bash
git clone https://github.com/TrisSun/Aimback.git ~/aimback-prod
cd ~/aimback-prod/backend
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

> 若 `python3 -m venv` 报错缺 ensurepip，先装 `python3.10-venv`。

### 3.3 配置 `.env`

`~/aimback-prod/backend/.env`（**生产必填项**，参考 `backend/.env.example`）：

```env
DEBUG=False
SECRET_KEY=<随机 50 位，勿泄露>
ALLOWED_HOSTS=118.25.145.183,localhost,127.0.0.1
REDIS_URL=redis://127.0.0.1:6379/0
STATIC_ROOT=/var/www/aimback/static

# ---- COS（图片上传，双桶）----
COS_SECRET_ID=AKIDxxxxxxxxxxxxxxxxxxxx
COS_SECRET_KEY=xxxxxxxxxxxxxxxxxxxxx
COS_REGION=ap-guangzhou
COS_BUCKET_ORIGINAL_PRIVATE=lostfound-original-1470644056
COS_BUCKET_THUMB_PUBLIC=lostfound-thumb-1470644056

# ---- 阿里云短信 ----
ALIYUN_PNVS_ACCESS_KEY_ID=
ALIYUN_PNVS_ACCESS_KEY_SECRET=
```

> 阿里云短信留空 = dev 模式（验证码直接返回在响应里），仅用于联调，生产必须补齐。

### 3.4 收集静态文件

```bash
cd ~/aimback-prod/backend
../venv/bin/python manage.py collectstatic --noinput
sudo chown -R www-data:www-data /var/www/aimback/static   # nginx worker 需要读权限
```

> 服务器 `.env` 里 `STATIC_ROOT` 指向 `/var/www/aimback/static`（**nginx 的 www-data 用户进不去 `/home/ubuntu`，静态文件必须放 `/var/www` 下**）。

### 3.5 Gunicorn systemd 服务

`/etc/systemd/system/aimback-backend.service`：

```ini
[Unit]
Description=Aimback Backend (Gunicorn)
After=network.target redis-server.service

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/aimback-prod/backend
ExecStart=/home/ubuntu/aimback-prod/venv/bin/gunicorn config.wsgi:application \
    --bind 127.0.0.1:8000 --workers 3 --timeout 60
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now aimback-backend
```

### 3.6 Nginx 反向代理

`/etc/nginx/sites-available/aimback`（default 站点需删除或 disable）：

```nginx
server {
    listen 80;
    server_name 118.25.145.183;

    location /static/ {
        alias /var/www/aimback/static/;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/aimback /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

### 3.7 建超管

```bash
cd ~/aimback-prod/backend
../venv/bin/python manage.py createsuperuser
```


## 6. 故障排查速查表

| 症状 | 排查方向 |
|---|---|
| 全部 502 | `sudo systemctl status aimback-backend`；看 gunicorn 是否挂了 |
| `/static/` 403 | 静态文件权限：`sudo chown -R www-data:www-data /var/www/aimback/static` |
| Admin 400 Bad Request | `.env` 的 `ALLOWED_HOSTS` 是否包含当前访问域名/IP |
| 限流不生效 / 计数异常 | 确认 `REDIS_URL` 已填且 `redis-cli ping` 通；各 gunicorn worker 共享 Redis 才生效 |
| 图片上传 403 | `.env` 的 COS 五项是否齐全；跨桶处理需 CAM 授权 `CI_QCSRole`（见 COS 文档） |
| collectstatic 报错 | `.env` 里 `STATIC_ROOT` 是否为绝对路径且目录可写 |
