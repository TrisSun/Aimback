# 接口契约更改日志

> 修订日期：2026-08-21
> 修订对象：`docs/接口契约.md`（Day 1 冻结稿 → Day 2 修订稿）
> 依据：《接口契约问题清单》（2026-08-18）+「最小改动」原则

## 一、修订原则

1. 优先让契约对齐现有后端骨架，而不是让代码迁就契约。
2. v0 沿用现有 token 鉴权与 DRF 默认错误格式；JWT、统一错误体、全局限流后置到联调后。
3. 保留查询参数 `event_start` / `event_end` 现名，不重命名为 `_at`，避免牵动 E 复用函数。
4. 除少数 `apps/posts/` 内小改外，不动 `config/`、`apps/accounts/`、`apps/storage/`、`requirements.txt`。

## 三、代码改动清单（最小范围）

仅涉及 `apps/posts/`：

- `serializers.py`：`custody_type`/`custody_place_id` 联动校验；`event_end_at <= now` 校验；`primary_color` 枚举校验（可选）。
- `views.py`：`sort` 排序、`q` 参数透传、`DELETE` 视图、非法状态转换返回 `409`。
- `urls.py`：新增 `posts/<int:pk>` 的 DELETE 路由。
- `filters.py`：`q` 关键词匹配（`title`+`description`+`attribute`）。
- `constants.py`：新增 `PRIMARY_COLOR_CHOICES`。

不修改 `config/`、`apps/accounts/`、`apps/storage/`、`requirements.txt`。
